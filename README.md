# Schutzgebiete

[Interaktive Karte direkt öffnen](https://delbasso.github.io/Schutzgebiete/)

Öffentliches Dashboard ohne Anmeldung. Aktueller Umfang: Baden-Württemberg. Eine deutschlandweite Erweiterung ist geplant und noch nicht Teil dieser Version.

Kartenebenen: NSG, WSG, Überschneidungen, Landwirtschaft, Ackerland und Kreise. Flächendefinitionen FIONA 2022 und LBM-DE 2021. SVG-/PNG-/CSV-Export und Quellenlinks.

Methodik, Datenstände und Quellenbedingungen: [Methodik_bw.txt](Methodik_bw.txt). Die Kennzahlen verwenden unvereinfachte Geometrien; die Kartendarstellung ist vereinfacht. Keine automatische Datenaktualisierung.
