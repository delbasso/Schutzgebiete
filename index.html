Eigene Flächendefinition

Du kannst eine vorberechnete Definition als JSON importieren, etwa eine andere Abgrenzung von Landwirtschaft. Die Datei muss dieselbe Schutzkulisse und dieselben Gebietsgrenzen verwenden. Prozentwerte werden aus Hektarangaben berechnet.

Der Import ersetzt keine Geodatenanalyse. Eigene Definitionsdaten zeigen zunächst keine Landwirtschaftsgeometrie; NSG, WSG und Kreisgrenzen bleiben sichtbar. Importierte Werte sind als ungeprüfte eigene Daten gekennzeichnet.

Der Import bleibt nur in dieser geöffneten Sitzung. Quellen und Beschreibung werden mit der Definition übernommen.
